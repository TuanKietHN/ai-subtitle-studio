## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Every implementation plan MUST answer these gates from the AI Subtitle Studio
Constitution. If a gate is not in scope for the feature, state `N/A` with a
specific rationale.

- **WhisperX stable pin**: Identify the stable PyPI WhisperX version pinned for
  the build and the ISO check date recorded in dependency metadata.
- **Mandatory VAD**: Show where the WhisperX wrapper forces
  `vad_method="pyannote"` and confirm no UI/config/API/request field can disable
  or replace it.
- **Model config**: Confirm default model `large-v3` and model options are loaded
  from config such as `models.json`, not hard-coded in UI logic.
- **System Info**: Confirm runtime display of WhisperX, `faster-whisper`, CUDA,
  GPU driver, selected model and app version, with package versions read via
  installed package metadata.
- **Interfaces**: Confirm STT engine and Translation provider are accessed via
  abstract base classes or `Protocol` contracts.
- **Worker execution**: Confirm audio extraction, transcription and translation
  run outside the UI thread with progress/error/cancel messaging.
- **Single GPU STT job**: Confirm GPU STT work is serialized through a global
  queue, lock or semaphore so only one video is transcribed on GPU at a time.
