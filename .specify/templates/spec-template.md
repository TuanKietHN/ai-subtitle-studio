### Constitution Impact *(mandatory for AI Subtitle Studio)*

For every feature, state whether it touches STT, translation, model selection,
System Info, worker processing or GPU scheduling. Include the applicable
constitution requirements below as functional requirements, not implementation
notes.

- **CI-001**: Features touching STT MUST preserve WhisperX as the STT engine and
  MUST NOT introduce `whisper.cpp` or OpenAI Whisper gốc.
- **CI-002**: Features touching transcription MUST require Pyannote VAD through
  `vad_method="pyannote"` as a non-configurable invariant.
- **CI-003**: Features touching model selection MUST keep `large-v3` as default
  and load available models from config such as `models.json`.
- **CI-004**: Features touching System Info MUST read installed package versions
  at runtime and include WhisperX, `faster-whisper`, CUDA/GPU driver, selected
  model and app version.
- **CI-005**: Features touching STT or translation MUST preserve provider
  interfaces based on abstract base classes or `Protocol` contracts.
- **CI-006**: Features touching long-running processing MUST keep heavy work off
  the UI thread.
- **CI-007**: Features touching GPU STT scheduling MUST preserve one active video
  STT job on GPU at a time.
